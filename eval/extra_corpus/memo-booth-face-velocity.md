# Technical Memo TM-11 — Booth Face Velocity (CONFLICTING-SOURCE TEST FIXTURE)

> Evaluation fixture only. Deliberately contradicts the SFB-300 manual.

## Overview & Specifications

This memo states the minimum extraction face velocity for the SFB-300
spray booth before spraying begins.

## Operating Procedures

Minimum booth face velocity before spraying: 0.3 m/s on the face-velocity
gauge. Start extraction and let airflow stabilize before spraying.
