# Dust Extraction & Collection System DCS-800 — Maintenance & Operations Manual (Rev. 0)

> SUPERSEDED: this revision predates the 2025-03-18 spark-detection and
> fire-suppression retrofit (Rev. A). It is retained in the corpus only
> as a historical record. This revision does not reflect the current
> spark detection module and must not be used for current safety
> procedures.

## Overview & Specifications

The DCS-800 is the central dust collection system serving the CNC
router, edge bander, and general sanding stations at Dawlia Furniture
Works' Damietta facility. Type: cyclone pre-separator with a baghouse
filter bank. Airflow capacity: 8,000 m3/h. At this revision, the system
does not yet include spark detection or automated fire suppression.

## Safety Prerequisites

1. Never run a connected machine (router, edge bander, sanders) with the
   DCS-800 offline.
2. Check baghouse differential pressure gauge before each shift.
3. Keep collected dust hoppers below the marked maximum fill line.
4. Do not open the hopper access door to clear a blockage without first
   confirming the auger has fully stopped at the control panel.

## Installation & Setup

Route all ductwork per the electrical contractor's bonding diagram.
Position ducting to minimize sharp bends that reduce airflow efficiency.

## Operating Procedures

Start the DCS-800 and confirm normal airflow before starting any
connected machine's dust-generating operation. Monitor the facility
dashboard during production for any fault or pressure-band alarm.

## Maintenance Schedule

Daily: check differential pressure gauge, check hopper fill levels.
Weekly: visually inspect ducting for damage or loose clamps. Monthly:
inspect baghouse filter bags for visible wear via the access port.

## Diagnostic & Troubleshooting

1. Symptom: baghouse differential pressure reading above the normal
   band. Likely cause: filter blinding from a heavy dust load.
   Corrective action: schedule filter inspection/replacement.
2. Symptom: differential pressure reading below the normal band. Likely
   cause: a torn filter bag or a duct disconnection. Corrective action:
   inspect filter bags via the access port, inspect ducting joints.
